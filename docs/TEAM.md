## How tasks move

1. Every task is a GitHub issue with a priority label (`priority: must`, `priority: should`, `priority: could`) and a group label.
2. Assign yourself before you start. Move the card to **In progress**.
3. Open a pull request that says `Closes #<issue>`. Ask someone else to review.
4. Close only when the [Definition of Done](DEFINITION_OF_DONE.md) is met.

## The 48-hour rule

If an assigned task shows no commit, pull request or comment for 48 hours, the Scrum Master unassigns it and the core builders pick it up. This keeps the build moving without blaming anyone.
